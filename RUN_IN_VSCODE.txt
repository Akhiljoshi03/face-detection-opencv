RUN IN VS CODE
==============
1. Unzip this folder, then in VS Code: File > Open Folder > face-detection-opencv
2. Open a terminal: Terminal > New Terminal
3. Run these one at a time:

   python -m venv venv
   venv\Scripts\activate            (Windows)
   source venv/bin/activate         (macOS/Linux)
   pip install -r requirements.txt
   python main.py

   (If "python" is not found on Windows, use "py" instead.)

4. A webcam window opens. Blue box = face found. ESC or q to quit.

If VS Code asks which Python interpreter to use, pick the one inside "venv".
Or press F5 to run using the built-in launch config.
